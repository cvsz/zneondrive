# Demo Runbook — ก่อนเข้าห้องประชุม

## 10 นาที ก่อนเริ่ม

1. Pull `main`.
2. Run:

```bash
python3 -m http.server 8080 --directory demo
```

3. Open `http://localhost:8080`.
4. Press `Ctrl+L` then `F11` or browser full-screen mode.
5. Verify TH/EN language toggle.
6. Click Foundry 9.
7. Switch Vehicle Lab through Street → Drift → Circuit → Off-road.
8. Reset Vertical Slice to MQ001.
9. Keep GitHub repository open in a second tab for evidence.

## Recommended meeting sequence — 15 minutes

- 0:00–1:30 — hook + project premise
- 1:30–3:00 — scale: 100 quests / 10 districts / 25 characters / 5 factions
- 3:00–5:00 — NOVA CITY + factions
- 5:00–7:00 — vehicle identity + VIP fairness
- 7:00–9:00 — MQ001–MQ012 demo to First Ignition
- 9:00–11:00 — architecture
- 11:00–13:00 — roadmap / engagement options
- 13:00–15:00 — decision questions

## Backup plan

If internet is unavailable, the demo is fully local.

If JavaScript is blocked, the page still presents the static hero and structural layout, but use the repository documents as backup.

## Do not claim

Do not say:
- production MMORPG is complete,
- anti-cheat is complete,
- HA/DR is proven,
- 100 quests are playable,
- all art/assets are production-ready.

Say:
- design and content contracts are complete to v0.2,
- vertical-slice specification is complete,
- core authority invariants are executable and tested,
- production stack direction is selected,
- the browser demo is presentation-ready,
- the next commercial milestone is the playable Unreal vertical slice.
