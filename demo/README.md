# Client Demo

This folder is a dependency-free browser presentation for PROJECT: NEON DRIVE.

## Run offline

From the repository root:

```bash
python3 -m http.server 8080 --directory demo
```

Open:

```text
http://localhost:8080
```

No package install, build step, CDN, external font, analytics, or API key is required.

## Presentation flow

1. Hero / project scale
2. NOVA CITY districts
3. Seven-chapter story spine
4. Vehicle build lab
5. MQ001–MQ012 first-session simulation
6. Server-authoritative architecture
7. Delivery roadmap
8. Client decision questions

## Important

This is a client-facing **interactive product concept / systems demonstrator**. It is not the production Unreal client and must not be represented as a finished playable MMORPG build.
