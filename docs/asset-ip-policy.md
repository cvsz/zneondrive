# Asset & IP Policy

## Goal

Keep repository and production assets legally traceable.

## Asset classes

- original ZeaZDev/project-created,
- commissioned/work-for-hire,
- licensed third-party,
- marketplace/store assets,
- open-source/open-content,
- temporary prototype/reference-only.

## Required metadata

For non-original assets retain:
- source/vendor,
- license,
- purchase/license proof where applicable,
- allowed platforms/seat/project restrictions,
- attribution requirement,
- modification/redistribution constraints.

## Repository rules

Do not commit:
- ripped game assets,
- unauthorized music,
- trademarked manufacturer branding used without permission,
- third-party source assets whose license forbids redistribution,
- confidential client assets without explicit authorization.

## Vehicles and branding

Original fictional vehicles should avoid copying distinctive protected trade dress/logos. Real-world brand licensing is a separate commercial/legal decision.

## AI-assisted assets

Track provenance and applicable usage terms for production assets created with generative tools. Do not assume concept-generation rights automatically satisfy platform/publisher/client requirements.

## Release gate

Production release requires an asset/IP clearance review for shipped art, audio, fonts, plugins, code and marketing materials.
