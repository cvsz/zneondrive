# Unreal Engine 5.8.2 Client Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install the verified Unreal Engine 5.8.2 archive, connect zNeonDrive, and produce evidence-backed Windows 11 and Android client releases.

**Architecture:** Keep Unreal as the gameplay client/server runtime and use the existing Go API, PostgreSQL, and Redis service boundaries. Build on Linux, package Windows and Android separately, and verify public API access plus local runtime behavior before release.

**Tech Stack:** Unreal Engine 5.8.2, Linux build host, C++/Blueprint project, Unreal AutomationTool, Windows 11 package target, Android SDK/NDK/JDK.

**Spec:** `docs/unreal-5.8.2-latest-status.md`

## Global Constraints

- Use `/mnt/workspace/UnrealEngine` as the extraction/install path.
- Never print or embed API tokens, shared keys, passwords, or signed download URLs.
- Preserve server-authoritative gameplay; the client must not become durable authority.
- Do not mark a gate complete without retained command output or artifact evidence.
- Keep Windows and Android packaging as separate reproducible outputs.
