# Maintainers

## Current maintainer

- GitHub: **@cvsz**
- Role: repository owner / final approver

## Responsibilities

Maintainers are responsible for:
- repository governance,
- architecture and ADR acceptance,
- security triage,
- release/status accuracy,
- stable ID/API compatibility,
- review of VIP/fairness-impacting changes,
- protection of credentials and player data,
- keeping evidence claims synchronized with actual CI/runtime results.

## Review expectations

Changes touching the following areas require maintainer review:
- `SECURITY.md`
- `docs/adr/`
- `design/catalog/` stable IDs
- persistence migrations
- authentication/session/game-ticket code
- reward/economy mutations
- ranked race authority
- entitlements/VIP behavior
- GitHub Actions and deployment configuration

This file should be updated when additional maintainers or formal code owners are added.
